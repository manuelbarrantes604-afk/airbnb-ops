# Airbnb Ops — permanent link

https://manuelbarrantes604-afk.github.io/airbnb-ops/

A tiny launcher page. It reads `url.json` (the board's current address, updated automatically
whenever it changes) and opens the live board full-screen. No data or code from the board lives here.

- `?p=/some/path` or `#/some/path` opens that path on the board.
- `?direct=1` redirects instead of embedding.
